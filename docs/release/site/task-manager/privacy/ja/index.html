Task Manager プライバシーポリシー

最終更新日: 2026年10月13日 · 開発者: Hoàng Dũng IT

本ポリシーは、アプリ「Task Manager」(Android、パッケージ名 com.taskmanager)がデータをどのように扱うかを説明します。要点: タスクはお使いの端末の中だけに保存されます。アカウントはなく、タスクをどこにも送信せず、第三者の分析ツールやクラッシュレポートも使いません。無料の Android 版には Google AdMob の広告が表示されます。Google Play で「広告を削除」を購入すると、以後アプリは広告をリクエストしません。

1. 入力したタスクと設定

タスク名、メモ、時刻、繰り返しのルール、リマインダー、設定は端末内にのみ保存されます。開発者、Google、その他の誰にも送信されず、クラウドにもバックアップされません。アプリをアンインストールするか、設定 → すべてのデータを削除を選ぶと、完全に削除されます。

問題の診断のため、アプリは端末内に小さなエラーログ(エラーコードと時刻のみ。タスクの内容は含みません)を保存します。このログが端末の外に出ることはありません。

2. 広告(Android、「広告を削除」を購入するまで)

広告は Google Mobile Ads SDK を通じて Google AdMob が提供します。Google の開示情報によると、この SDK は広告、分析、不正防止のために次の情報を自動的に収集し、Google と共有します。

  • 端末の識別子: Android の広告 ID とアプリセット ID
  • IP アドレス(端末のおおよその位置の推定に使われることがあります)
  • アプリの操作: アプリの起動、広告のタップ、動画の視聴
  • 診断情報: 起動時間など、アプリと SDK のパフォーマンス

これらのデータは送信時に暗号化されます(TLS)。タスク名やメモが広告ネットワークに送信されることはありません。Google はこのデータを自社のポリシーに従って取り扱います: Google のサービスを使用するサイトやアプリから収集した情報の Google による使用。

EU、EEA、英国、スイスでの同意。これらの地域では、広告をリクエストする前に Google の同意フォームが表示されます。選択はいつでも設定 → 広告 → プライバシー設定で変更できます。選択内容は IAB TCF の形式で端末内に保存されます。

ご自身でできること。広告 ID は Android の設定(機種により「設定 → Google → 広告」または「設定 → プライバシー → 広告」)でリセットまたは削除できます。「広告を削除」を購入すると、広告のリクエストはすべて停止します。

3. 「広告を削除」の購入

購入は Google Play が処理します。開発者がカード情報や支払い情報を受け取ることはなく、Google が Google プライバシーポリシーに従って取り扱います。オフラインでも購入を覚えておくため、アプリは購入状態と Google Play が返す取引記録(取引トークンを含む)を端末内に保存します。この記録は開発者に送信されず、クラウドにもバックアップされません。

4. アプリが使用する権限

  • 通知と正確なアラーム: 時間どおりにお知らせするため。リマインダーをオンにしたときにのみ求めます。
  • インターネットとネットワークの状態: 広告の読み込みと、Google Play での購入確認のため。
  • 広告 ID(AD_ID と Android のプライバシー サンドボックスの権限): 第2項のとおり Google Mobile Ads SDK が使用します。

5. お子様について

本アプリは 13 歳未満のお子様を対象としておらず、お子様のデータを意図的に収集することはありません。

6. 保存期間と削除

開発者はサーバーを持たず、お客様のデータを一切保管しません。端末内のデータは、アプリのアンインストールまたはすべてのデータを削除で削除されます(購入は Google Play アカウントに紐づくため保持されます)。広告や Google Play を通じて Google が収集したデータは、Google のポリシーに従って保存・削除されます。

7. iOS 版

iOS では広告を表示せず、販売も行いません。第2項と第3項は適用されません。

8. 本ポリシーの変更

本ポリシーを変更した場合は、このページと上記の「最終更新日」を更新します。
